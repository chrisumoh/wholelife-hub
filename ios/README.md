# Whole Life for iOS (SwiftUI preview)

A native SwiftUI recreation of the Whole Life web app's main screens, so the look can be judged on an iPhone. It uses local sample data and does not sync with Supabase. The web app (`index.html`) is untouched.

## Run it
1. Install Xcode 16 or newer from the Mac App Store.
2. Open `ios/WholeLife.xcodeproj` (double-click it).
3. Pick an iPhone simulator at the top (for example "iPhone 16") and press the Play button (or Cmd+R).

Screens: Summary, Daily nutrition, Workouts, Coach, and More (Recipes, Food culture, Achievements, Settings). Needs iOS 17 or newer. Food lists are text only, West African first, as in the web app.
